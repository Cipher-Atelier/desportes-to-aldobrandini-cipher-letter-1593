# Desportes 1593

Author: Maxim Egorov

Selected passages from a partial working reconstruction of the letter attributed to Baudouin Desportes, written to Pietro Aldobrandini in Paris on 22 July 1593. The investigation applies Satoshi Tomokiyo’s published polyphonic key and preserves the later comparison with Paolo Rosson’s reading.

- [Complete published article](article.md)
- [Methods](methods.md)
- [Readings and unresolved comparisons](readings.md)
- [Sources and prior work](sources.md)

The full working French reading, coordinate ledger and verification apparatus are not included. No new cipher key, complete solution or global priority is claimed.
